# 国产模型图像生成测试分析报告

## 项目概述

本项目对 **5 种国产图像生成模型** 与 **GPT-5.5 模型** 在 **6套标准测试用例** 上的表现进行了测试、对比、分析。

---

## 测试内容

### 被测模型

| 类别 | 模型名称 |
|------|----------|
| 国产模型 1 | 万相 |
| 国产模型 2 | 即梦 |
| 国产模型 3 | 文心 |
| 国产模型 4 | 混元 |
| 国产模型 5 | 智谱 |
| 参考模型 | GPT-5.5 |

### 测试用例

共设计 **6 套测试用例**，覆盖以下维度：

1. 海报
2. PPT
3. UI/UX
4. Logo
5. 数据和图表
6. 日志可视化
